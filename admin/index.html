Quản trị nội dung website

Sửa chữ, đổi ảnh, bật thông báo, thêm hoặc bớt mục trên lotusmigrate.com. Bấm “Xuất bản” là website tự cập nhật sau 1–2 phút.

  1. Mở trang tạo token của GitHub (đăng nhập tài khoản quản lý repo).
  2. Đặt tên Lotus admin, chọn thời hạn (ví dụ 90 ngày).
  3. Repository access → Only select repositories → chọn lotus-global-immigration.
  4. Permissions → Contents → Read and write. Không cần quyền nào khác.
  5. Bấm Generate token, sao chép và dán vào ô dưới.

Token chỉ lưu trong trình duyệt của bạn và chỉ gửi tới GitHub. Không gửi token qua chat, email hay cho người khác. Nếu lộ token, vào GitHub → Settings → Developer settings → Fine-grained tokens để thu hồi.
